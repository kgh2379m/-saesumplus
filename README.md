# 새숨더함 — 공식 홈페이지

> **"사람의 공간과 관계에 정성을 더하는 홈케어 브랜드"**

---

## 프로젝트 개요

새숨더함 공식 브랜드 홈페이지입니다.  
단순한 서비스 소개 페이지가 아닌, **브랜드 철학을 스토리텔링 방식으로 전달**하는 경험 중심의 웹사이트입니다.

방문자는 스크롤을 내릴수록 새숨더함의 철학 → 서비스 가치 → 플랫폼 비전 → 파트너 생태계의 이야기를 순서대로 경험하게 됩니다.

---

## 완성된 기능

### UI / 섹션 구성
| 섹션 | 설명 |
|------|------|
| **Hero** | 브랜드 철학 첫 화면 (배경 이미지 + 시적 문구 + CTA) |
| **Story 01** | 왜 새숨더함이 존재하는가 (신뢰 중심 메시지) |
| **Story 02** | 정성은 기술보다 먼저 (갤러리 이미지 3컷) |
| **Story 03** | 함께 성장하는 상생 (파트너 태그) |
| **Story 04** | 새숨더함 스케줄러 (인터랙티브 Mockup UI) |
| **Story 05** | 홈케어오더나눔 (Coming Soon + 진행률 바) |
| **Story 06** | 브랜드 드림 — 가장 신뢰받는 홈케어 |
| **Story 07** | 5대 서비스 소개 (카드 그리드) |
| **Story 08** | 파트너 혜택 6가지 |
| **고객 후기** | 4개 실제 후기 카드 |
| **블로그** | 3개 콘텐츠 카드 (SEO 구조 포함) |
| **문의하기** | 연락처 + 폼 (Table API 연동) |
| **Footer** | 철학 재등장 + 회사 정보 + SNS |

### 인터랙션 & 애니메이션
- 스크롤 기반 Navbar 배경 전환 (투명 → 화이트)
- Intersection Observer를 활용한 섹션별 Reveal 애니메이션
- Hero 배경 Parallax 스크롤 효과
- 스케줄러 Mockup UI (다크 테마, 캘린더 컴포넌트)
- 오더나눔 진행률 프로그레스 바 (IntersectionObserver 트리거)
- 숫자 카운터 Up 애니메이션 (Stats 카드)
- 서비스 카드 Hover 오버레이
- Back to Top 버튼
- 모바일 햄버거 메뉴

### 데이터
- **문의 폼** → `tables/inquiries` (RESTful Table API)
  - `name`, `phone`, `service`, `message`, `submitted_at` 저장

## 파일 구조

```
index.html          메인 단일 페이지
css/
  style.css         전체 스타일 (변수 기반, 반응형)
js/
  main.js           인터랙션 및 API 연동
```

## 주요 기능 URL 경로

| 경로 | 설명 |
|------|------|
| `/` or `/index.html` | 메인 홈페이지 |
| `/#story01` | Story 01 — 브랜드 이야기 |
| `/#story04` | Story 04 — 스케줄러 소개 |
| `/#story05` | Story 05 — 홈케어오더나눔 |
| `/#story07` | Story 07 — 서비스 목록 |
| `/#story08` | Story 08 — 파트너 신청 |
| `/#contact` | 문의 / 예약 폼 |
| `tables/inquiries` | 문의 데이터 API (GET/POST) |
