# 대표 답글 + 새 후기 알림 설치 안내 (Apps Script)

홈페이지 코드(`js/main.js`)는 이미 준비되어 있습니다.
**구글 시트 쪽 Apps Script를 아래대로 교체·배포해야 실제로 동작합니다.**

## 1. 코드 교체 (약 5분)

1. 후기 응답이 쌓이는 **구글 시트**를 엽니다.
2. 상단 메뉴 **확장 프로그램 → Apps Script**.
3. 기존 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여넣습니다.
4. 맨 위 `CONFIG.OWNER_PIN`을 **본인이 쓸 숫자 4자리**로 바꿉니다. (`'0000'` 그대로 두지 마세요)
5. 저장(💾).

## 2. 웹 앱 새 버전 배포 (URL 유지가 중요!)

1. 우측 상단 **배포 → 배포 관리**.
2. 기존 웹 앱 배포의 ✏️(수정) 클릭 → 버전: **새 버전** → 배포.
   - 실행 사용자: **나**, 액세스 권한: **모든 사용자** (기존과 동일)
   - 이렇게 해야 홈페이지에 적힌 URL(`REVIEWS_API`)이 그대로 유지됩니다.
   - "새 배포"를 만들면 URL이 바뀌어 `js/main.js`의 `REVIEWS_API`도 바꿔야 합니다.
3. 권한 승인 요청이 뜨면 허용합니다. (시트 읽기/쓰기, 메일·외부 요청)

## 3. 새 후기 알림 설정 (폰으로 바로 받기)

`CONFIG`에서 **쓰고 싶은 방법만** 채우면 됩니다. 여러 개 동시 사용도 가능합니다.

| 방법 | 난이도 | 설정 |
|------|--------|------|
| **Gmail 앱 푸시** (추천·가장 쉬움) | ★ | `NOTIFY_EMAIL`에 내 Gmail 주소 입력. 폰 Gmail 앱 알림만 켜져 있으면 끝 |
| **텔레그램** (즉시·무료) | ★★ | 텔레그램에서 `@BotFather`로 봇 생성 → 토큰을 `TELEGRAM_BOT_TOKEN`, 봇에게 말을 건 뒤 내 chat id를 `TELEGRAM_CHAT_ID`에 입력 |
| **ntfy 앱** (가입 불필요) | ★ | 폰에 ntfy 앱 설치 → 추측 어려운 주제 이름(예: `saesum-review-x7k2q9`)을 앱에서 구독하고 `NTFY_TOPIC`에 같은 값 입력 |

> 카카오톡 "나에게 보내기"는 카카오 개발자 앱 등록·토큰 갱신이 필요하고, 카카오 채널 알림톡은 유료라 권장하지 않습니다.

### 트리거 등록 (최초 1회)
1. Apps Script 편집기 상단 함수 선택에서 **`installTrigger`** 선택 → ▶ 실행 → 권한 승인.
2. **`testNotify`** 를 실행하면 테스트 알림이 폰으로 오는지 확인할 수 있습니다.
3. 이후 구글 폼으로 후기가 제출될 때마다 자동 알림이 발송됩니다.

## 4. 대표 답글 사용법

1. 홈페이지 고객후기 영역 하단의 **[대표 로그인]** → 숫자 4자리 입력.
2. 각 후기 카드 아래 **[답글 쓰기]** 버튼이 나타납니다. (수정·삭제도 가능)
3. 답글은 시트의 `대표답글` 탭에 저장되고 모든 방문자에게 보입니다.
4. 로그인은 현재 브라우저 탭에만 유지되며, 탭을 닫으면 해제됩니다. 공용 PC에서는 [대표 로그아웃]을 눌러 주세요.

## 보안 참고

- 비밀번호 검증은 서버(Apps Script)에서 하므로 화면 코드에는 번호가 없습니다.
- 5회 연속 틀리면 10분간 로그인이 잠깁니다. (방문자 구분 없이 전체 적용)
- 숫자 4자리는 간단한 수준의 보호입니다. 더 높은 보안이 필요하면 자릿수를 늘리세요.
